# UPS-POD — zakres v8

Dodano klikalne logo, naprawiono nachodzenie FBA na stałą kolumnę checkboxów, kopertę zgłoszenia do UPS (również po 24 h od skanu Out for Delivery), imię i nazwisko oraz e-mail pracownika w konfiguracji. Główny Gmail SMTP z hasłem aplikacji nie wymaga GCP; historyczny formularz OAuth jest ukryty. Automatyczne powiadomienia pracownika obejmują brak POD ponad dobę po końcu terminu oraz zmianę Delayed na Delivered; wymagają potwierdzonego logowania SMTP lub istniejącego OAuth i adresu pracownika, są deduplikowane oraz grupowane w SQLite, bez ponawiania wysyłki o nieznanym wyniku. Dane UPS są dostępne w rozszerzonym wyborze kolumn, z reindeksacją historycznego pełnego JSON bez zmiany POD. Kolumny przeliczane według mierzonej treści po zmianie widoczności. Paginacja górna jest zintegrowana z narzędziami, UPS API jest nową etykietą. Import arkuszy pozostaje osobnym etapem, opisanym w UPS_POD_IMPORT_SHEETS_PLAN.md.
