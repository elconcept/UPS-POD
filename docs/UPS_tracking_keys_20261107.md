# UPS Tracking API — wszystkie klucze zaobserwowane 7.11.2026

Źródło: **rzeczywista odpowiedź produkcyjnego Tracking API**, HTTP 200, `locale=pl_PL`. Poniżej wymieniono wszystkie zaobserwowane ścieżki kluczy JSON z tej odpowiedzi. `[]` oznacza element tablicy. To **nie jest pełny katalog opcjonalnych pól z dokumentacji UPS**: pola mogą zależeć od przesyłki, uprawnień i parametrów. W panelu Logi dostępny jest zbiorczy rejestr kluczy zaobserwowanych później, bez przechowywania ich wartości.

W odpowiedzi istnieje **`trackResponse.shipment[].pickupDate`**, format `YYYYMMDD`. Tekst statusu: `trackResponse.shipment[].package[].currentStatus.description`, w tym przypadku po polsku. Kod statusu: `currentStatus.code`. POD: `deliveryInformation.pod.content` w Base64. Sam dokument POD HTML pozostaje angielski mimo `locale=pl_PL`.
