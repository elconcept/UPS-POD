Gmail — nadawca zgłoszeń UPS

Sprawdzanie…

Bez Google Cloud i bez OAuth Client ID. Wystarczy adres skrzynki Google oraz odrębne 16-znakowe hasło aplikacji dostępne dla kont z weryfikacją dwuetapową. Nie wpisuj zwykłego hasła Google.

Hasło aplikacji można utworzyć na koncie Google. Niektóre konta Google Workspace nie dopuszczają haseł aplikacji (zależy od polityki administratora). Próba „Sprawdź logowanie” nie wysyła wiadomości.

Zaawansowane: OAuth 2.0 (wymaga klienta Google)

Alternatywa dla kont bez haseł aplikacji. OAuth wymaga zarejestrowanej aplikacji Google; sama biblioteka nie zastępuje Client ID i Secret.

W Google Cloud Console utwórz klienta OAuth 2.0 typu „Aplikacja internetowa” i włącz Gmail API. Dodaj jako dozwolony redirect URI:

https://ups.xlap.pl/api/config/gmail/callback

Po zalogowaniu przyciskiem Google konto będzie mogło wysyłać zgłoszenia do UPS. Token odświeżania jest przechowywany na serwerze, poza przeglądarką. Nie wysyłamy zgłoszeń bez kliknięcia w kolumnie „Dokument”.
